# Changelog

## 0.1.0 (unreleased)

First public release.

* The cloud: orbs with depth, blur and dimming, tag lines with emphasis and labels, spring physics, drag and throw, pop-in on arrival, travel by wheel, trackpad and pinch, fly-through, and an elastic floor at the end of the collection.
* Lazy loading through `loadMore`, list replacement through `setItems`.
* Events: `activate`, `focus`, `move`, `blur`, `travel`.
* Every tunable number is a setting, changeable live with `configure`.
* Optional bubble companion, `driftfield/bubbles`.
* ES module and script-tag builds, type definitions, no runtime dependencies.

The interface may still change before 1.0.
